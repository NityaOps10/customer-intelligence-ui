# Customer Intelligence

A calm, clean, data-dense customer feedback analytics web app for product and marketing teams. Built with React 19, TypeScript, and Tailwind CSS.

## Features
- **Insights Dashboard**: Cards with synthesized claims, feedback volume, trend deltas, strength signals, and low data flags.
- **Evidence Drawer**: Side drawer displaying supporting customer quotes, star ratings, sources, and highlighted text spans.
- **CSV Export**: Export all supporting evidence reviews for any insight in RFC 4180 CSV format.
- **Light & Dark Mode**: Seamless toggle with system detection and local persistence.
- **Mock & Live API Mode**: Switchable via `VITE_USE_MOCK` in `.env`.

## Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
